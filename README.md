##Repositorio para adicionar desafios do site codeWars##

1️⃣ Inverter Palavras
Descrição: Escreva uma função que recebe uma string e retorna a mesma string com as palavras que tenham 5 letras ou mais invertidas.

2️⃣ Troll Remover
Descrição: Crie uma função que recebe uma string e remove todas as vogais  (a, e, i, o, u) dela.

3️⃣ Máximo e Mínimo
Descrição: Implemente duas funções: uma que retorna o maior número de uma lista de inteiros e outra que retorna o menor.
